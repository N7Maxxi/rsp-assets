# rsp-assets

Image host repo for the Revenge of the Savage Planet Kindex Tracker (n7maxxi.com).
Upload this folder's CONTENTS to the GitHub repo N7Maxxi/rsp-assets (public, branch main).
The tracker loads images from https://raw.githubusercontent.com/N7Maxxi/rsp-assets/main/

- kindex/  : cropped Kindex entry photos, named <planet>-<category>-<entry>.jpg
